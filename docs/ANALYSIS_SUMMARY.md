# Analysis Summary

1. **Independent Transcriptomic Analyses**: Both bulk and single-cell datasets identify strong unfolded protein response (UPR) and ER stress signatures.
2. **Cross-Dataset Convergence**: Despite different cell types (hNPCs, hepatocytes, dendritic cells), a core module of genes is consistently dysregulated.
3. **miRNA Regulatory Evidence**: The core genes are heavily targeted by an infection-responsive pool of miRNAs.
4. **Candidate Prioritization**: CHAC1, ASNS, and other ER-stress regulators emerge as central hubs, representing actionable therapeutic vulnerabilities for broad-spectrum flavivirus inhibition.
