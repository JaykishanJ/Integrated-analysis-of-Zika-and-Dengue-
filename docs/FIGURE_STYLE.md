# Figure Style Guide

## Principles
- **Typography**: Arial or Helvetica, consistent font sizing (e.g., 8pt for axes, 10pt for titles).
- **Format**: All final figures are generated as 600 DPI SVG/TIFF files.
- **Color Palette**:
  - ZIKV: Teal/Blue
  - DENV: Red/Orange
  - Mock: Grey
- **Dimensions**: Formatted for 1-column (85mm) or 2-column (170mm) Nature/Cell standard widths.
