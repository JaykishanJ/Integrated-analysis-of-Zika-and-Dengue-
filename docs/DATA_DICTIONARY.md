# Data Dictionary

## Common Metadata Fields
- sample_id: Unique identifier for the sequencing library/sample.
- condition: Experimental condition (e.g., Mock, ZIKV, DENV).
- infection_status: Cellular state determined by viral reads (e.g., Infected, Bystander, Unexposed).
- 	issue: Origin tissue/cell type (e.g., hNPC, Huh7, moDC).
- hpi: Hours post-infection (e.g., 4, 12, 24, 48).
